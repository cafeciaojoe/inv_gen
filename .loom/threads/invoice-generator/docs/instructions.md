# Documentation

A README in the repo, written for Joe rather than for a developer.

- [ ] Setup on a new Mac: Homebrew, then `brew install uv pango`
- [ ] Install: clone, then drag `make_invoices.py`, `Make invoices.command` and
      `template/` into the invoicing folder. Update by dragging them in again.
- [ ] The monthly routine: paste from Notion, double-click, read the drafts, type
      `commit`. What to do when it refuses.
- [ ] What each file in the folder is, and which ones never to edit by hand
- [ ] Changing the library date (`exclude-newer`), and running the tests
- [ ] Brief is final: check it matches what was built
